# 3D Printing (Using Web Control)
1. Open 3D printer GUI: `http://192.168.1.51` (3D printer's IP address)
2. Select the `Job` folder and choose the desired G-code file.
3. Press `Yes` to start the 3D printing task.
4. Check that the heat bed temperature is increasing.
5. Ensure the heat bed is clean.
6. If the nozzle is not clean, then clean it when the extruder is heated.
7. Clean the nozzle gently using a pair of pliers or forceps.
8. Wait for the auto bed levelling calibration to complete.
